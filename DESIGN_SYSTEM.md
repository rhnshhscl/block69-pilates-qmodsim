# Design system

- Editorial olive-charcoal and brass theme reflects the cafe studio. The light palette uses parchment and charcoal. Canvas colors follow CSS custom properties.
- Georgia for editorial headings, system UI for text and monospace telemetry. Cards use single borders and modest radii.
- Three top-level views share a responsive shell. Scenarios place the incident library beside the walkthrough, Lab places controls beside the class floor and plots, and Codex groups derivations and the legal crosswalk.
- Real buttons and labelled inputs support keyboard use. Simulation movements honor reduced-motion preferences for the Markov animation. Plot summaries are available as text.
